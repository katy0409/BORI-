# BORI V1.3 — Cloud Life

## V1.3 新增
- Supabase Email 註冊、登入、登出
- 登入狀態保存
- 共同帳本雲端同步
- 邀請碼加入帳本
- 收入、支出、預算雲端同步
- 即時聊天室
- BORI 熊熊貼圖
- 多帳本切換
- RLS 權限與 Realtime SQL

## 第一次使用
1. 把全部檔案上傳 GitHub Pages。
2. 在 Supabase SQL Editor 執行 `backend-setup.sql`。
3. 打開 BORI，貼上 Supabase Publishable Key。
4. 註冊帳號並開始使用。

Project URL 已預填為目前的 BORI Supabase 專案。
請勿使用或公開 Secret Key。
