# BORI 보리｜共同生活記帳 App v3

這是一個可以直接部署到 GitHub Pages 的手機版共同記帳 App。

## 本版新增

- BORI 啟動畫面（Splash Screen）
- 韓文／英文 Logo 與中文品牌標語
- 熊抱麥穗的封面視覺
- 1.9 秒淡入淡出動畫
- PWA manifest
- 手機主畫面圖示
- Apple Touch Icon
- Service Worker 離線快取
- 建立帳本、共同支出、自動分帳、分析與資料清除

## 上傳 GitHub

將本資料夾內所有檔案與 `assets` 資料夾一起上傳到 Repository 根目錄：

- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- assets/
- README.md

GitHub Pages 會自動重新部署。

## 加到 iPhone 主畫面

使用 Safari 開啟 BORI 網站，點「分享」→「加入主畫面」。

## 加到 Android 主畫面

使用 Chrome 開啟網站，點右上角選單→「安裝應用程式」或「加到主畫面」。
