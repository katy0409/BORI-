# BORI 보리｜共同生活記帳 App MVP

這是一個不需安裝套件即可執行的前端 MVP。

## 執行方式

1. 解壓縮專案。
2. 直接雙擊 `index.html` 開啟。
3. 或使用 VS Code 的 Live Server 開啟，體驗會更穩定。

## 已完成功能

- 多個共同帳本
- 新增支出
- AA 分帳與欠款試算
- 支出分類分析
- 付款排行
- LocalStorage 本機資料保存
- 新增帳本
- 手機版響應式介面
